# 1.0.29 — 2026-09-11

[English](1.0.29.md)

## 错误修复

- **Pager 中的 Tab 导航** 会在提示、滚动区和整个 dock 之间干净循环，而不再停在每个 dock 分区。
- **Ctrl+G** 可隐藏或显示 pager 中的 dock；隐藏时焦点回到滚动区。
- **同一 GROK_HOME 下多个并发 `grok agent stdio`** 进程启动时不再崩溃。
- **MCP 服务器连接** 不再对 2026-07-28 的现代服务器失败。
- **修复** Windows 在未启用 Client-ProjFS 可选功能时的启动崩溃。

## 性能

- **Agent dashboard** 在只有空闲旋转指示或隐藏行时不再浪费 CPU 重绘相同帧。
