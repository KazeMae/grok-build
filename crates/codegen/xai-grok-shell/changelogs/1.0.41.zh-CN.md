# 1.0.41 — 2026-09-22

[English](1.0.41.md)

## 新功能

- **新增 `sports_search` 工具**，可直接从 X 数据查询实时的 NFL 比分、排名、赛程、球员数据和球队战绩。
- 在 /settings 中**新增子智能体模型继承设置**；该设置会写入 config.toml，并遵循 managed/overlay 层级。
- **按模型配置请求体大小上限**：现在可以配置以匹配服务商的 HTTP body 上限，并控制内联图片的淘汰。
- **长推理提醒**现在可通过配置启用，在模型进行长时间隐藏推理后给予提示。

## 错误修复

- **修复**子智能体全屏视图，头部不再多出一个 [Dashboard] 按钮。
- **修复** agent frontmatter 中的 `mcpServers`：当前 agent 的 agent.md 提供的 headers 与 URL 现在会正确覆盖 config.toml，并在配置重载或 agent 切换后保留。
- **Ctrl+P** 现在可在欢迎界面直接打开命令面板。
- **Dashboard** 现在会聚焦 “+ New Agent” 行，而不再保持之前选中的会话。
- 因崩溃而中断的会话现在会显示明确的标记，而不再静默丢弃该回合。
- **Ctrl+Z** 在暂存提示词后立即按下，现在会将其恢复。
- **折叠编辑块**设置现在即使 `expanded_by_default` 被固定为 true，也能正确折叠编辑内容。
- 插话现在会先得到一条可见回复，智能体随后再继续先前的任务。
- 取消因 spawn_subagent 阻塞的回合时，现在会告知模型子任务已转入后台，而不再声称其从未执行。
- 保存排队提示词的编辑后，现在会把焦点交回输入框，下一次按键即输入下一条消息。
- 子智能体的启用状态在 TUI 与 `grok agent stdio` 之间保持一致；仅设置 limits 或 models 的配置表不再禁用子智能体。
- **推理强度选择**现在除 ID 外也接受菜单标签。
