# 1.0.26 — 2026-09-09

[English](1.0.26.md)

## 新功能

- **向子智能体插入消息（interject）** 会打断长时间的后台等待，消息立即送达。
- **滚动区中的子智能体消息行** 会标明该消息是 interject、排队还是 steer。
- **反馈表单** 可在 minimal 模式直接使用，无需切到全屏。

## 错误修复

- **`/btw` 旁路提问** 会带上编辑器中附加的图片。
- **后台任务提醒** 不再回显原始 shell 命令。
- **失败的后台任务** 在模型读完输出后不再产生重复提醒。
- **压缩期间的 TPM 限流错误** 会重试，而不再被当成上下文溢出。
- **回合早期 Ctrl+C** 现在能正确回退提示，没有竞态。
- **Dashboard 方向键** 可从空输入框导航操作行。
- **旧版 MCP 服务器上的工具调用** 现在正确声明 elicitation 支持。
- **Memory v2** 会从初始化失败中恢复，并避免反复出错后捕获卡住。
